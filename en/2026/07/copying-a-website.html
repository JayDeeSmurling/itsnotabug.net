Copying a website

Have you ever wondered how to quickly backup your website?

If you use Linux, you have the powerful WGET tool at your disposal.

It also works on MacOS, but you must have the HomeBrew package installed first.

If you have a Mac, skip to the next step.

Linux

In the terminal, type

`wget --mirror --convert-links --adjust-extension --page-requisites --no-parent http://example.org`

The individual parameters mean:

`--mirror`

Enables "mirror" mode—that is, combining several options: recursive downloading, unlimited depth, and "time-stamping" (recording date/modifications), which makes it easier to re-sync content. This allows Wget to keep up with the structure of the entire site—subdirectories, subpages—by downloading (theoretically) all available content.

`--convert-links`

Once the download is complete, Wget changes all links in the documents (HTML, CSS, hyperlinks, images, etc.) to point to locally downloaded files—usually as relative paths. If the link points to a resource that Wget didn't download, that link is converted to a full address with hostname and path, preventing "broken links." This allows you to browse the site locally after downloading—clicking and navigation work as if you were online (as long as the resources were downloaded).

`--adjust-extension`

If the downloaded resource is of type text/html or application/xhtml+xml, and its URL doesn't end in '.html' or '.htm', Wget adds the .html extension when saving the file. This ensures that the file will be correctly recognized by the browser—which can be important, especially when the server generates pages dynamically (e.g., CGI scripts) and the URL ends, for example, with ?id=25, without an extension. Note: files modified in this way may be re-downloaded the next time they're mirrored, because Wget may not recognize that the local file corresponds to a URL—if the URL without an extension never indicated it was an HTML page.

`--page-requisites`

It downloads all the resources necessary to properly display the page, such as style sheets (CSS), images, scripts, and fonts—not just the HTML file itself. This ensures that the local copy of the page looks and behaves very similarly to the original—with images, styles, and so on.

`--no-parent`

When Wget works recursively, by default it may also start sorting and downloading "parents" in the directory structure (e.g., higher-level directories). --no-parent blocks this behavior—Wget doesn't ascend directories. In practice, this means you only download the content at the address you specify (and the subpages/documents below), not the entire domain or parent directories.

MacOS

For MacOS systems, wget is available as a homebrew package. Detailed instructions for installing this package can be found here.

Once the installation is complete, wget will work just like it does in Linux.
